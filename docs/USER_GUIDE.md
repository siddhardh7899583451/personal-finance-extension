# User Guide

## Quick start

1. Install the extension (Load unpacked).
2. Click the toolbar icon.
3. Add an expense or income from the popup.
4. Click **Open Dashboard** for charts, budgets, and reports.

## Adding transactions

- **Popup:** fastest path for daily capture.
- **Dashboard → Transactions → + Add:** full form.

Fields: title, amount, category, date, optional payment method.

## Budgets

Dashboard → Budgets → New budget. Choose overall or category (future category picker), period, and amount. Utilization updates from expense transactions.

## Savings goals

Set a target and optional deadline. Use **Contribute** to add progress. Progress bar and percentage update immediately.

## Insights

Insights and anomalies are computed from your data only. With few transactions, some insights are marked as estimates. Anomalies are statistical (high amount, frequency, possible duplicates) — **not** fraud labels.

## Reports & backup

- **Export JSON:** full snapshot (recommended for backup).
- **Export CSV:** transactions only.
- **Import JSON:** replaces current data after confirmation.

## Theme & currency

Settings panel (or theme button) controls light/dark and default currency. Amounts are stored in minor units of the transaction’s currency.
